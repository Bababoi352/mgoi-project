# 唔该计划 / M’GOI PROJECT

可编辑、无依赖的响应式静态网站框架。五个栏目：首页、可视化、手册、档案、关于。没有填入实际作品、照片、研究数据或正式长文。

## 运行

安装 Node.js 18+，在本目录运行 `npm run dev`，打开 http://127.0.0.1:5173 。无需安装依赖。也可运行 `node server.mjs`。不要直接双击 HTML，模块需要 HTTP 服务。

## 编辑

- data.js：通用作品布局位置、格式分类和章节索引；双语字段为 `[中文, English]`。
- app.js：页面模板、详情、章节阅读区与交互。所有内容均标注待录入。
- style.css：排版、灰度背景、蓝色强调与响应式样式。
- 首页背景是代码绘制的抽象等高线，不是真实地图或作品。网站不引用用户的参考摄影或参考截图。旧参考画板仅保留在本地 assets 文件夹，不包含在新版交付包中。

## 动画与交互

- 切换页面：420ms 淡入与轻微上移。
- 滚动入场：段落、索引行和卡片逐段出现；卡片轻微错开。
- 首页空白媒体块：缓慢上下浮动。
- 导航下划线、卡片悬停反馈，以及“向下探索”的平滑滚动。
- 自动尊重系统“减少动态效果”偏好，关闭动画。
- 双语切换与语言保存、作品格式筛选、档案筛选、章节导航、作品详情。

调整速度：app.js 的 main.animate 与 style.css 的 .reveal / @keyframes float。动画不依赖第三方库。旧 Systems 链接跳转到可视化索引。

## 检查与部署

`npm run check` 检查语法。另检查五个导航、语言切换、筛选、章节跳转及桌面和手机布局。

纯静态网站无需构建：托管 index.html、app.js、data.js、style.css 即可；加入正式图片后再托管所用 assets。Hash 路由不需要服务器重写，资源采用相对路径，支持仓库子路径。GitHub Pages 可以选择对应分支及根目录发布；其他静态服务同样可用。

当前未绑定远程 GitHub 仓库，未创建 PR。

## 实体书与影像

手册页只排列四本不同比例的书籍。点击打开双页，通过书页、左右箭头或键盘方向键翻动；Esc 或关闭按钮返回。每本书的空白页数仅用于演示，不是正式作品。

在 media.js 的 books[].pages 中填入书页图片路径（建议偶数页，顺序为左页、右页）；size 控制各本书比例。空字符串表示空白页。影像页只有一个居中的框，点击后打开原生视频播放器。在 media.js 的 film.src 填入 assets/film.mp4 或可访问的视频文件地址；film.poster 可选。当前没有视频文件，界面显示“视频待添加”，未模拟播放。接入后点击框即可开始播放；浏览器阻止自动播放时可使用播放器的播放按钮。

部署时请包含 media.js，以及实际使用的书页图片和视频。页面翻动继续尊重“减少动态效果”设置。

## 可视化海报

原 Archive 栏目现为“可视化海报 / Posters”，仍使用 #/archive 地址以兼容原链接。页面排列三个竖版空白海报位置，不再显示档案分类和研究材料。替换 app.js 的 archive() 中 .poster-sheet 内容即可添加正式海报图片，建议保持 2:3 比例；移动端采用单列排列。
